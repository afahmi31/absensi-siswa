**AC-01 — Template dan batas berkas**
Template .xlsx memakai header tetap C03: Nama, NIPD, Jenis Kelamin, Tanggal Masuk, Tanggal Keluar. Nama wajib. Simpan NIPD sebagai teks agar nol di depan tidak hilang; tanggal memakai format ISO; tanggal masuk boleh kosong (jika kosong, gunakan awal semester), dan tanggal keluar boleh kosong; jenis kelamin boleh kosong, L, atau P. Workbook hanya berisi satu sheet data dengan header tetap. Tolak beberapa sheet, header tambahan, formula, makro, gambar/objek tertanam, dan format lain dengan pesan yang jelas. Batas unggahan 5 MB, 500 baris, dan 20 MB untuk total isi ZIP setelah dibuka. Tolak ZIP dengan entri ganda, path traversal, enkripsi, terlalu banyak entri, atau ukuran menyerupai zip bomb. Batas ini mengikuti keputusan C03 dan bukan perkiraan jumlah siswa sekolah.

**AC-02 — Preview terikat dan pilihan duplikat**
Simpan preview di database/berkas privat, tidak dapat diubah klien, dan ikat pada guru/semester. Gunakan token acak yang kedaluwarsa setelah 30 menit. Tampilkan data baris dan error hanya-baca serta duplikat terhadap data yang sudah ada dan duplikat dalam berkas. Jangan mempercayai nama, NIPD, atau tanggal baru dari body commit; body hanya membawa pilihan masukkan/tambah berbeda/lewati. Jika baris invalid ikut dipilih, tahan seluruh commit. Minta pilihan eksplisit untuk setiap duplikat. Jika nama yang sama muncul setelah preview, minta preview baru atau laporkan konflik.

**AC-03 — Commit dan pengulangan permintaan**
Simpan semua baris pilihan yang valid secara atomik; server memeriksa ulang status tertutup, kepemilikan, tanggal, dan versi data. Token yang sudah dipakai menyimpan hasil; pengulangan mengembalikan hasil yang sama tanpa membuat data tambahan, dan commit bersamaan tidak membuat duplikat. Jika terjadi kegagalan, batalkan perubahan siswa, keanggotaan, dan audit bersama-sama. Jangan menimpa atau menggabungkan identitas yang sudah ada.

**AC-04 — Tampilan dan perlindungan data**
UI menyediakan pilihan berkas, preview, error baris, keputusan per baris, dan ringkasan jumlah. Tampilkan sukses hanya setelah commit server berhasil. Jika gagal, pertahankan pilihan berkas. Terapkan batas autentikasi, origin, dan ukuran. Respons dan log tidak boleh memuat isi mentah berkas atau kredensial.

**AC-05 — Pemeriksaan dan laporan**
Gunakan data uji (fixture) .xlsx nyata untuk data opsional, duplikat, invalid, formula, batas ZIP, pengulangan request, kondisi bersamaan, dan semester tertutup. Pastikan template unduhan dapat dibuka. PM mengunggah fixture nyata melalui browser dan membandingkan jumlah dengan data tersimpan. Jalankan typecheck/build dan laporkan evidence aktual.
